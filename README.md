# 내 통합 서재

여러 플랫폼의 저장 작품과 PC 소설 폴더를 한 곳에서 관리하는 개인용 목록 앱입니다. 작품 본문, 로그인 정보, 구매 정보는 저장하지 않습니다.

## 실행

`내-통합-서재-1.0.0.exe`를 실행합니다. 개발 중에는 `index.html`을 최신 Chrome 또는 Edge에서 열어도 됩니다.

## 목록 가져오기

- **카카오페이지/리디:** 저장 목록을 한 줄씩 복사해 `목록 붙여넣기`에서 가져옵니다. 형식은 `제목 | 작가 | 완결/연재중 | 링크`입니다. 작가·상태·링크는 생략 가능합니다.
- **내 폴더:** `폴더에서 가져오기`를 누르고 폴더를 선택합니다. txt, epub, pdf, mobi, azw3, zip, cbz의 파일 이름과 상대 경로만 읽습니다. 파일을 열거나 옮기지 않습니다.
- **카카오페이지/리디 자동 목록:** Chrome 또는 Edge의 확장 프로그램 관리 화면에서 `개발자 모드`를 켠 뒤 `압축해제된 확장 프로그램 로드`로 `browser-extension` 폴더를 선택합니다. 각 서비스의 보관함 화면에서 확장 아이콘을 누르면, 화면에 표시된 작품 제목·링크만 JSON 파일로 내보냅니다. 앱 상단의 `플랫폼 목록 파일` 버튼으로 그 JSON을 가져옵니다. 로그인 정보, 쿠키, 작품 본문은 읽거나 저장하지 않습니다.
- **백업:** 모든 목록은 브라우저의 로컬 저장소에 저장됩니다. 정기적으로 `백업 내보내기`를 사용하세요.

## 정렬

- 제목순: 숫자 → 영문 → ㄱㄴㄷ
- 완결 상태순: 완결 → 연재중 → 미확인
- 플랫폼순 또는 작가순
